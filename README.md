# RecomEngine — 팀 프로젝트

GitHub에서 **기존 실행본**과 **새 작업물**을 한눈에 구분하도록 정리했습니다.

| 폴더 | 역할 |
|---|---|
| [기존프로젝트/](기존프로젝트/) | 현재 팀 프로젝트에서 사용하는 전체 코드(프론트엔드·백엔드·데이터·테스트) |
| [새작업물/](새작업물/) | 각자가 따로 만들고 테스트한 작업물을 **작업별 독립 폴더**로 업로드하여 팀원과 공유 |

## 새 작업물 공유 방법

1. 각자 새 기능이나 변경 사항을 **별도 폴더/프로젝트로 개발**합니다. 본인의 환경에서 실행하고 오류를 확인합니다.
2. `새작업물/` 바로 아래에 **작업명 또는 작성자_작업명**으로 새 폴더를 만듭니다. 프론트엔드·백엔드·DB 등 정해진 폴더에 맞출 필요는 없습니다.
3. 그 폴더에 **실행 가능한 작업 코드와 README.md**를 올립니다. README에 실행법, 테스트 결과, 변경한 기능, 기존 프로젝트에서 교체할 파일/기능, 미해결 사항을 적어 주세요.
4. 팀원들이 새 작업물을 **독립적으로 실행·검토**합니다.
5. 승인된 작업의 **필요한 부분만** `기존프로젝트/`에 반영한 뒤 기존 기능까지 함께 테스트합니다.

예시(아래 폴더들은 실제로 미리 생성되어 있지 않습니다):

```text
새작업물/
├── README.md
├── 추천알고리즘_개선/
│   ├── README.md
│   └── (독립 실행에 필요한 코드)
└── 설문화면_개편/
    ├── README.md
    └── (독립 실행에 필요한 코드)
```

> **주의:** `새작업물/`의 파일은 `기존프로젝트/`에서 자동으로 실행되거나 연결되지 않습니다. 작업별로 서로 독립적인 구조와 실행법을 유지한 뒤, 팀 검토가 끝나면 필요한 변경만 통합합니다. 단, 특정 파일 하나만 복사하면 실행되지 않을 수 있으니 의존성·설정·연결 지점을 README에 반드시 적어 주세요.

## 기존 프로젝트 실행

폴더 구조 내부는 기존과 동일하며, 실행할 때만 `기존프로젝트/`로 이동하면 됩니다.

**백엔드 — Windows PowerShell (저장소 루트에서)**

```powershell
cd 기존프로젝트
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
$env:USE_MOCK_DB="true"
python -m pytest
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

**프론트엔드 — 별도 PowerShell (저장소 루트에서)**

```powershell
cd 기존프로젝트/frontend
npm ci
npm test
npm run build
npm run dev
```

- 프론트엔드 화면: http://localhost:5173
- 백엔드 API 문서: http://127.0.0.1:8000/docs
- 자세한 기존 설명: [기존 프로젝트 README](기존프로젝트/README.md) · [프론트엔드 README](기존프로젝트/frontend/README.md)

## 오류 방지 원칙

- `기존프로젝트/` 내부의 `app/`, `frontend/`, `data/`, `scripts/` 상대 배치는 변경하지 않습니다. Python과 Vite 명령을 실행할 때 **해당 디렉터리에서 실행**하세요.
- 팀원이 제출한 새 작업물은 바로 기존 코드를 덮어쓰지 않고, 독립 실행 확인 → 팀원 검토 → 부분 적용 순으로 진행합니다.
- 변경 반영 시 Python 테스트와 React 테스트·빌드를 반드시 다시 실행합니다. [GitHub Actions](.github/workflows/verify.yml)가 기존 프로젝트를 자동 검사합니다. **새 작업물의 독립 테스트는 각 제출자가 별도로 수행**해야 합니다.
- `.env`, API 키, 개인 데이터는 GitHub에 올리지 않습니다. 실제 Supabase 쓰기 및 SQL 적용은 DB 담당자 동의 후 진행합니다.
