# 비회원 진단 세션 회원 계정 연결 개선

## 변경 내용
- 진단 세션 생성 직후 세션 ID를 프론트 상태에 기록합니다.
- 회원가입/로그인 요청에 guest_session_ids를 포함합니다.
- 완료된 비회원 진단 세션을 계정에 원자적으로 연결하는 Supabase RPC를 추가합니다.
- RPC는 service_role만 실행할 수 있고, 이미 소유자가 있거나 미완료 세션은 이전하지 않습니다.
- Mock DB RPC 구현 및 API 테스트를 추가했습니다.

## 적용
이 폴더의 파일을 저장소 내 같은 상대 경로에 반영하세요. SQL은 Supabase 마이그레이션으로 이미 프로젝트에 적용하고 실행 권한을 확인했습니다.
