# 개인페이지

기존 HTML 개인페이지 화면에 내 활동·플레이 성향·설정과 Python 저장 기능을 연결하는 작업물입니다.

- [통합용 코드](구현코드/): Python 저장 계층, 기존 화면용 JavaScript, 카드 CSS
- [통합 방법](구현코드/연결방법.md)
- [자동 테스트](테스트/test_personal.py)
- [화면 점검 순서](테스트/화면점검.md)

로그인/회원가입, 설문 계산, Steam 수집 코드는 포함하지 않습니다. 기존 모듈에 연결해 사용합니다. SQLite는 로컬 검증용 저장 구현이며 운영 DB 통합 시 저장 계층을 교체할 수 있습니다.

점검: 자동 테스트 9개와 JavaScript 문법 검사 통과. 실제 브라우저 전체 클릭/시각 검증은 미완료이며 화면 점검 순서에 별도 구분했습니다.
