# 검증 구분

자동 검사(통과):
```sh
python -m unittest discover -s 테스트 -p 'test_*.py' -v
node --check 구현코드/personal.js
```
테스트는 임시 DB와 별도 게임 fixture를 사용합니다. 테스트가 끝나면 임시 DB를 삭제합니다.

통합 후 브라우저에서 확인할 항목(미완료):
1. 7문항 완료 → 개인페이지에 자동 프로필 및 활성 성향 표시.
2. 첫 상태에는 만들기 카드만, 생성 후 기존 카드와 추가 카드 표시.
3. 기존 게임 상세 열기 → 내 활동 최근 조회 표시, 중복 없이 최신 순서.
4. 기존 찜 버튼 추가/해제 → 내 활동 반영.
5. 설정 꾸미기에서 닉네임·소개·아이콘·게임 배경·위치·어둡기 저장 → 새로고침 유지.
6. 카드 이미지는 가장자리 흐림 없이 비율을 유지하고 꽉 채워지는지 확인.
7. 다른 계정에서는 타 계정 프로필과 활동이 노출되지 않는지 확인.
8. 회원가입 게스트 이전과 재로그인 복원은 계정 모듈과 함께 점검.

자동 테스트 통과는 브라우저 시각/클릭 검증 완료를 의미하지 않습니다.
