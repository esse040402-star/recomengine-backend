# 새 작업물 공유

여기는 팀원들이 **각자 만든 새로운 작업물을 독립적으로 실행·검증한 뒤 공유하는 폴더**입니다.

프론트엔드, 백엔드, 데이터베이스 등으로 미리 폴더를 구분하지 않습니다. 작업을 시작할 때마다 이 폴더 아래에 **새로운 작업별 폴더**를 만들면 됩니다.

예시 (실제 폴더를 미리 생성한 것은 아닙니다):

```text
새작업물/
├── README.md
├── 설문_화면_개편/
├── AI추천_개선/
└── 스팀리뷰_기능/
```

## 작업별 폴더 제출 기준

- **독립 실행 확인:** 제출한 폴더에 해당 작업물을 실행하는 데 필요한 코드·설정 예시·의존성 파일을 포함합니다.
- **README.md 필수:** 작업 목적, 실행 방법과 실행 환경, 개인 테스트 결과, 기존 프로젝트에 적용할 파일/부분, 적용 시 주의사항을 적습니다.
- **팀원 검토:** 팀원은 제출 폴더만 살펴보고 별도로 실행·검증할 수 있어야 합니다.
- **부분 통합:** 검토를 마친 후 **필요한 코드만** [기존프로젝트/](../기존프로젝트/)에 반영합니다. 제출 폴더가 기존 애플리케이션에 자동으로 연결되는 일은 없습니다.
- **다른 제출물 보존:** 각자 새 폴더를 만들어 공유하고, 기존 제출물을 임의로 덮어쓰지 않습니다.

### 제출 폴더의 README 예시

```markdown
# 작업 이름
작성자: 
주요 변경 기능: 

## 실행 방법
- 필요한 환경 / 의존성:
- 실행 명령:
- 정상 동작 확인 방법:

## 개인 테스트 결과
- 확인한 기능:
- 결과 / 남은 오류:

## 기존 프로젝트에 적용할 부분
- 대체하거나 수정할 기존 파일:
- 필요한 API·DB·설정 변경:
- 팀원 검토 결과:
```

**보안:** 토큰, API 키, 비밀번호, 실제 DB 데이터, `.env` 파일을 업로드하지 마세요. 새 작업물별 테스트 결과는 기존 프로젝트의 자동 테스트와 별개입니다.
