# 원본 대비 변경 내용

비교 대상: `recomengine.zip`(원본)과 `recomengine update ver.1.zip`(수정본).

- 수정 파일: 14개
- 수정본에만 존재: `.env` 1개 (업로드 제외)
- 원본에만 존재: 0개
- 삭제 파일: 0개

## 변경 파일
- `app/db.py`
- `app/routers/account.py`
- `app/routers/survey.py`
- `app/services/accounts.py`
- `frontend/src/App.jsx`
- `frontend/src/components/common/DialogContents.jsx`
- `frontend/src/components/common/Modal.jsx`
- `frontend/src/components/layout/AppLayout.jsx`

- `frontend/src/state/AppContext.jsx`

- `frontend/src/utils/storage.js`

## 주요 변경 영역
- 회원가입 시 이메일 인증 필요 여부 처리 및 인증 완료 후 세션 설정
- 설문 질문 조회 API 추가
- 비회원의 빠른 진단 완료 후 앱 접근 허용
- 게스트 데이터 7일 보관 및 만료 처리
- 계정별 저장, 미전송 상태 복구 및 서버 저장 흐름
- 공통 모달, 레이아웃, 추천 서비스 요청 처리

## 검증
작업자는 기능 테스트가 모두 정상 작동했다고 보고했습니다. 이번 업로드 과정에서는 테스트를 재실행하지 않았습니다.
