# 사용방법

이 폴더는 원본 프로젝트에 적용할 변경 파일 모음입니다. 저장소 루트 기준 동일한 상대경로에 파일을 배치해 검토하세요. 기존 프로젝트 전체를 대체하지 마세요.

## 설치
- 백엔드: 저장소 루트에서 `pip install -r requirements.txt`
- 프론트엔드: `frontend`에서 `npm install`
- 필요한 환경변수는 이 폴더의 `.env.example`을 복사해 로컬 `.env`를 만들고 실제 환경에 맞게 설정하세요. 실제 키와 비밀번호는 GitHub에 올리지 마세요.

## 실행
- 백엔드: 저장소의 기존 실행 명령을 사용하세요.
- 프론트엔드: `frontend`에서 `npm run dev`

## 테스트
- 프론트엔드 빌드: `frontend`에서 `npm run build`
- 프론트엔드 테스트: `frontend`에서 `npm test`
- 백엔드 테스트: 저장소 루트에서 `pytest`

테스트는 작업자가 정상 작동을 확인했다고 보고했습니다. 이번 업로드 과정에서 재실행하지 않았습니다.
