# 게임 정보 데이터 출처 및 통합 기준

수집 스크립트: `scripts/collect_game_info.py` · 정리 코드: `app/services/game_info_merge.py`
결과 파일: `data/collected/games.json`, `data/collected/games.csv`

## 1. 원칙

- **칸 이름 앞부분이 출처입니다.** `steam_…` 은 Steam, `igdb_…` 는 IGDB 값입니다.
- **이름 통일은 하지 않습니다.** 장르·태그·테마·플레이 방식은 각 API가 준 표현 그대로 저장합니다 (예: Steam `RPG`, IGDB `Role-playing (RPG)`).
  표현 통일은 `새작업물/API가중치_분류통합` 의 공통 사전(`vocabulary.json`, `normalization.py`)에서 합니다.
- 두 출처의 값을 섞거나, 한쪽이 비었다고 다른 쪽 값으로 채우지 않습니다. 화면/DB에서 어느 값을 쓸지는 사용하는 쪽에서 고릅니다.
- 리뷰 본문, 가격, PC 사양은 저장하지 않습니다 (화면에서 Steam API로 실시간 조회).

## 2. 수집 대상과 사용한 API

- 대상: `data/catalog_apps.json` 의 게임 (프론트 카탈로그, Steam AppID 기준) + 옵션으로 추가하는 **Steam 인기 게임**
  - `--top N`: SteamSpy(steamspy.com, Steam 통계 사이트) 전체 목록에서 Steam 리뷰 수(긍정+부정)가 많은 순 N개
  - `--top-per-genre N`: SteamSpy 인기 목록 상위 약 3,000개를 후보로, **IGDB 장르**별(기본 Adventure, Role-playing (RPG), Shooter, Strategy, Simulator, Indie, Platform, Puzzle, Racing, Sport)로 리뷰 수 많은 순 N개씩. SteamSpy 장르별 목록(`request=genre`/`tag`)은 2026-11-17 확인 시 빈 값만 돌려줘서 사용하지 않음
  - SteamSpy는 **어떤 게임을 받을지 고르는 데만** 씁니다. 저장되는 값(리뷰 수 포함)은 모두 Steam·IGDB에서 다시 받은 값입니다.
  - Steam `type` 이 `game` 이 아닌 앱(DLC, 사운드트랙, 데모, 소프트웨어)은 제외하고 `collect_report.json` 의 `not_a_game_excluded` 에 기록합니다.

| 출처 | 주소 | 받는 것 |
|---|---|---|
| Steam 상점 | `store.steampowered.com/api/appdetails` (`l=english`, `l=koreana`, `cc=kr` → 없으면 `cc=us`) | 이름, 이미지, 설명, 장르, 카테고리, 플랫폼, 출시일, 개발사·배급사, 무료 여부 |
| Steam 리뷰 | `api.steampowered.com/IUserReviewsService/GetAppReviews/v1/` (모든 언어, 전체 기간, `purchase_type=1`) | 긍정·부정 리뷰 수. 예전 `appreviews` 주소는 이제 HTML을 돌려줘서 공식 리뷰 API 사용 (팀 백엔드 `steam.py` 와 같은 요청 값) |
| IGDB | `api.igdb.com/v4/external_games` → `games` | Steam AppID로 연결된 IGDB 게임의 ID, 이름, 요약·줄거리, 장르, 테마, 키워드, 시점, 게임 모드, 멀티플레이 상세, 플랫폼, 최초 출시일, 회사, 이미지 |

## 3. 항목별 출처

| 필수 항목 | 칸 (출처) | 비고 |
|---|---|---|
| 게임 고유 ID | `steam_app_id` (Steam), `igdb_id` (IGDB) | 연결 기준은 아래 4 |
| 게임 이름 | `steam_name` (Steam 영어 상점), `steam_name_ko` (Steam 한국어 상점, 영어와 다를 때만), `igdb_name` (IGDB) | |
| 대표·헤더 이미지 URL | `steam_header_image`, `steam_capsule_image` (Steam) / `igdb_cover_image` (세로 표지, `t_cover_big`), `igdb_artwork_image` (`t_1080p`) (IGDB) | 이미지 파일은 저장하지 않고 URL만 |
| 게임 설명 | `steam_short_description`, `steam_description` (Steam, 한국어 → 없으면 영어) / `igdb_summary` (IGDB, 영어) | HTML 태그 제거, 3,000자에서 자름 |
| 줄거리 | `igdb_storyline` (IGDB, 영어) | 없는 게임이 많음 |
| 장르 | `steam_genres` (Steam, 영어 표기) / `igdb_genres` (IGDB) | |
| 태그·테마 | `igdb_themes`, `igdb_keywords`, `igdb_player_perspectives` (IGDB) | Steam 사용자 태그는 appdetails에 없어 수집 안 함 |
| 플레이 방식 | `steam_categories` (Steam) / `igdb_game_modes`, `igdb_multiplayer_modes` (IGDB) | Steam 카테고리에는 업적·클라우드 같은 기능 표시도 함께 들어 있음. `igdb_multiplayer_modes` 는 true 인 항목 이름 (`onlinecoop`, `offlinecoop`, `splitscreen` …) |
| 지원 플랫폼 | `steam_platforms` (`windows`/`mac`/`linux`, Steam) / `igdb_platforms` (IGDB) | 모바일 제외 (아래 4) |
| 출시일 | `steam_release_date` (`YYYY-MM-DD`), `steam_release_date_text` (원문), `steam_coming_soon` (Steam) / `igdb_first_release_date` (IGDB, 전 플랫폼 최초) | Steam 원문이 "Coming soon" 처럼 날짜가 아니면 `steam_release_date` 는 빈 값 |
| 개발사·배급사 | `steam_developers`, `steam_publishers` (Steam) / `igdb_developers`, `igdb_publishers` (IGDB) | |
| Steam 리뷰 수 | `steam_positive`, `steam_negative`, `steam_review_total` (Steam) | 모든 언어·전체 기간, 팀 백엔드 리뷰 집계와 같은 기준. 리뷰 조회만 실패하면 게임은 저장하고 이 칸만 빈 값 |
| 무료 여부 | `steam_is_free` (Steam) | 값이 없으면 빈 칸 (무료로 취급하지 않음) |

## 4. 통합 기준 (이 스크립트가 직접 하는 것)

1. **게임 연결:** Steam AppID → IGDB 외부 링크 표(`external_games`)에서 **Steam 상점으로 표시된 링크**만 사용합니다. 다른 상점(GOG 등) 번호가 우연히 같아도 쓰지 않습니다.
   - 이름만 같은 게임은 연결하지 않습니다 (공통 사전 `필드통합기준.md` 의 ID 정책과 같음). 연결 못 한 게임은 `igdb_` 칸이 비고 `collect_report.json` 의 `igdb_not_linked` 에 남습니다.
   - 한 AppID에 IGDB 게임이 여러 개 연결된 경우(에디션 등): Steam 이름과 같은 것 → 없으면 IGDB ID가 가장 작은 것.
2. **모바일 제외:** IGDB 플랫폼 중 Android, iOS, Windows Phone, Windows Mobile, BlackBerry OS, Palm OS, N-Gage 등은 `igdb_platforms` 에서 빼고 `excluded_mobile_platforms` 에만 기록합니다. (Steam은 PC용이라 해당 없음)
3. **형식 정리:** HTML 제거, 날짜를 `YYYY-MM-DD` 로, IGDB 이미지 ID → 이미지 URL, 같은 목록 안의 중복 제거.

## 5. 파일 형식

- `games.json`: `{"meta": {수집 시각, 개수, 출처}, "games": [게임 …]}` — 목록은 배열
- `games.csv`: 엑셀용 (UTF-8 BOM). 목록 칸은 `" | "` 로 이어 붙임, 참/거짓은 `TRUE`/`FALSE`, 빈 값은 빈 칸
- `collect_report.json`: 실패한 게임, IGDB 연결 안 된 게임, 게임이 아닌 앱(DLC 등), 칸별 빈 값 개수

## 6. 알려진 한계

- IGDB 요약·줄거리는 영어입니다.
- 한국 상점에서 팔지 않는 게임은 미국 상점(`cc=us`) 정보로 채웁니다.
- 리뷰 수와 설명은 수집한 시점 기준입니다. 최신 값이 필요하면 `--refresh` 로 다시 실행하세요.
