# 첫7문항

## 실행
1. Python 3.10 이상을 설치합니다.
2. Windows에서 `설문_실행.bat`을 실행합니다.
3. 브라우저에서 게이머/비게이머 7문항에 답한 후 결과를 확인합니다.
4. 계산 결과는 `results/` 폴더에 JSON으로 저장됩니다.

## 테스트
`테스트_실행.bat` 또는 `python -m unittest discover -s tests -v`

종료: 실행 창에서 `Ctrl+C`

## Steam 정보와 추천 확인
설문 제출 뒤 저장 결과를 열면 기기 조건에 맞는 게임 중 양수 점수 상위 5개를 확인할 수 있습니다. JSON의 matched_weights는 각 게임에서 확인된 가점·감점이며 합계가 score입니다.

팀 백엔드가 없어도 저장소의 Steam 상세·카탈로그에서 추출한 136개 게임 자료로 동작합니다. 팀 API를 실행한 경우 아래 명령으로 갱신한 뒤 새 설문을 제출하세요. 기존 응답 기록은 유지됩니다.

    python -m quick_survey.refresh --base http://127.0.0.1:8000 elden
    python -m quick_survey.refresh --base http://127.0.0.1:8000

첫 명령은 한 게임, 두 번째는 전체를 갱신합니다. API의 game 매개변수는 Steam 번호가 아니라 프로젝트 ID입니다. 실패한 게임은 기존 정보를 유지합니다.

기기는 후보 필터, 세션·그래픽·회피요소는 팀이 직접 분류한 게임만 반영합니다. 장르와 싱글·협동·대전은 Steam 분류를 사용합니다. 사무용 PC 선택은 최소 RAM 4GB 이하 및 내장 그래픽 지원이 명시된 경우에만 가점입니다. 가격은 최소 화폐 단위 원본값이며 예산을 묻지 않으므로 점수에는 넣지 않습니다. 태그나 조작 방식에 확인 가능한 근거가 없으면 해당 점수를 게임에 적용하지 않습니다.
